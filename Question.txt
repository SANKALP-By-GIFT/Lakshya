🧪 SDP Open Book Examination
Project Option: LMS Assignment Submission UI (Frontend Only)

Duration: 5 Hours (Development)
Evaluation: 2:00 – 4:00 PM (Demo + GitHub Review)
Difficulty Level: Medium → Moderate Advanced (MCA Level)
Backend: ❌ Not Allowed (Use Mock API Only)

📌 Problem Statement

Design and implement a Learning Management System (LMS) – Assignment Submission Interface as a Single Page Application using React.

The system must simulate:

Role-based login (Student / Instructor)

Assignment dashboard

Assignment submission flow

Mock grading interface (Instructor view)

Protected & role-based routing

Server-state management using React Query

The objective is to evaluate:

Auth & protected routes

Role-based access control

Server vs client state separation

Component composition

Testing & clean architecture

Instructor
